# 6. Le « sampling » du modèle de diffusion

Comme pour le LLM, **une même demande peut produire plusieurs résultats**. Avec le prompt « un fauteuil en velours rouge dans un salon », le fauteuil, sa position ou la composition peuvent varier.

Le modèle de diffusion part d’un **bruit aléatoire** : si ce point de départ change, le débruitage peut aboutir à une autre image, tout en suivant la même description.

Si vous utilisez un modèle libre dans une interface qui propose ce réglage, la **seed** vous permet de fixer ce bruit de départ. En conservant la même seed, le même prompt, le même modèle et les mêmes réglages, vous pouvez reproduire la même image dans les mêmes conditions de génération.
