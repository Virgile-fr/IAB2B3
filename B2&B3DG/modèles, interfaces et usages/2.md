# 2- Modèle ≠ interface

Aujourd’hui, la plupart des grands services réunissent plusieurs capacités dans **une seule interface**.

Ce n’était pas forcément le cas auparavant, et tous les acteurs ne proposent toujours pas les mêmes types de modèles ou les mêmes fonctions.

L’interface est ce que vous utilisez directement.

Le modèle est l’une des briques qui travaille derrière cette interface.

**ChatGPT**, par exemple, est une interface qui peut mobiliser différents modèles et outils selon ce que vous lui demandez :

- générer du texte ;
- analyser une image ;
- produire une image ;
- rechercher une information ;
- lire un document ;
- effectuer certains calculs ou utiliser du code.

L’interface peut sélectionner automatiquement les outils nécessaires ou, dans certains cas, vous laisser choisir le modèle utilisé.

À l’inverse, certains services sont davantage spécialisés.

Un acteur comme **Anthropic**, avec Claude, ne propose par exemple pas exactement les mêmes capacités qu’OpenAI ou Google.

Il existe également des interfaces comme **Mamouth**, que nous utiliserons aujourd’hui, dont le principe est différent : elles permettent d’accéder depuis un même endroit à des modèles provenant de plusieurs entreprises comme OpenAI, Anthropic ou Google.

> **À retenir :**
>
> **Le modèle est une brique du système.  
> L’interface est la manière dont vous y accédez et dont ces différentes briques sont organisées.**
