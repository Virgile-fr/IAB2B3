# 4. Le « sampling » du LLM

Si vous écrivez **« Le chat s’est endormi sur le »**, plusieurs suites sont possibles : *canapé*, *lit* ou *tapis*. Le modèle attribue une probabilité à chaque token en fonction de ce qu’il a appris et du contexte.

Le **sampling** consiste à sélectionner le prochain token parmi ces possibilités. Le modèle ne choisit pas systématiquement le plus probable : une part de hasard peut intervenir, tout en favorisant les suites les plus probables.

Ce choix influence ensuite la suite du texte. Avec « canapé », on pourrait poursuivre la description d’un salon ; avec « toit », raconter une scène différente. Chaque token sélectionné rejoint le contexte et influence le choix suivant.

C’est l’une des raisons pour lesquelles **un même prompt peut produire des réponses différentes**. Pour vos projets, cette variation permet d’explorer plusieurs propositions, qu’il faut ensuite comparer selon vos intentions.
