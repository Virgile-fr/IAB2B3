# 7. Les hallucinations

Les modèles peuvent produire un résultat convaincant mais contenant des erreurs, dans le texte comme dans les images.

**Dans le texte**, on parle d’**hallucination** lorsque le modèle présente une information inventée comme un fait, notamment lorsqu’il manque d’informations dans son entraînement ou utilise mal celles dont il dispose.

Par exemple, il peut proposer un tutoriel bien expliqué, mais indiquer des **options inexistantes**, ou celles d’une ancienne version du logiciel si ses connaissances précèdent votre version.

Quand le sujet demande de la précision, demandez-lui **des sources avec des liens** plutôt qu’une réponse directe, pour vérifier vous-même les informations. S’il faut des informations récentes, précisez : **« Dans ta recherche sur Internet, cible les résultats de moins de X mois/jours/heures. »**

**Dans les images**, on parle plutôt d’**incohérences visuelles**, comme les mains mal formées, fréquentes avec les premiers modèles. Malgré les progrès, certains détails peuvent encore être déformés. **Précisez la composition dans votre prompt** et limitez les retouches successives, qui peuvent altérer les détails. Un passage dans **Photoshop** reste parfois nécessaire, par **inpainting**, qui régénère uniquement la zone sélectionnée, ou avec les outils d’édition classiques.
