# 3- Les modèles de langage : LLM

Le **LLM** génère du texte en prédisant chaque mot suivant, en s’appuyant sur :

- **Son entraînement** : ce que le modèle a appris à partir des données utilisées pour l’entraîner.
- **Votre prompt** : la demande que vous lui formulez et qui guide la génération.
- **Le contexte** : les documents, les exemples ou les échanges précédents que vous lui mettez à disposition.

Le principe du **LLM** est à peu près similaire à celui du **prédicteur de votre téléphone**, qui vous suggère le mot suivant lorsque vous écrivez un message. Le LLM tient toutefois compte d’un contexte beaucoup plus riche et répète ce processus pour construire une réponse entière.

On parle de « mot » pour simplifier, mais le modèle utilise des **tokens**, qui peuvent correspondre à un mot ou à une partie de mot. Chaque token généré rejoint le contexte et influence la prédiction suivante : ce que le modèle vient d’écrire guide aussi la suite de sa réponse.

> **À retenir :** le LLM construit sa réponse progressivement, en prédisant le token suivant.
