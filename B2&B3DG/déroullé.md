Lundi matin : IA + conception éditoriale

- 0h00 à 0h30 : Comprendre les outils
  - Les différents modèles et outils regroupés sous le mot « IA »
  - Modèle et interface : rôles, outils et accès à plusieurs modèles avec Mamouth
  - Modèles de langage : entraînement, prompt, contexte et génération token par token
  - Modèles de diffusion :o génération à partir de bruit, rôle du prompt et entraînement au débruitage
  - Sampling : principes simples

- 0h30 à 0h50 : Limites et précautions
  - Hallucinations, biais, 
  - résultats génériques
  - Droit d’auteur
  - droit à l’image
  - Données personnelles / confidentielles
  - Toujours vérifier les informations importantes

- 0h50 à 1h10 : Démo LLM
  - Un prompt vague produit un résultat générique
  - Ajouter contexte, cible, contraintes
  - Critiquer puis corriger la réponse

- 1h10 à 1h20 : Pause

- 1h20 à 2h00 : Cadrage du projet
  - Sujet
  - Cible / persona
  - Objectif du site
  - 1 à 3 pages
  - Interaction envisagée
  - B3 : repartir du Figma réalisé jeudi

- 2h00 à 2h40 : Architecture du contenu
  - Rôle de chaque page
  - Sections
  - Hiérarchie des informations
  - CTA / actions importantes

- 2h40 à 3h40 : Rédaction avec le LLM
  - Titres, accroches, descriptions, contenus
  - Travail page par page
  - Vérifier, couper, réécrire
  - Supprimer les formulations trop génériques

- 3h40 à 4h00 : Point collectif
  - Vérification de quelques projets
  - Identifier les visuels nécessaires pour l’après-midi

- À obtenir :
  - Structure complète du site
  - Textes relus et corrigés
  - Liste des visuels à produire
  - Document de suivi commencé : prompts + corrections
  
Lundi après-midi : images + direction graphique
- 0h00 à 0h30 : Construire un prompt image
  - Sujet
  - Composition
  - Cadrage / camera shots
  - Angle
  - Lumière
  - Matières
  - Ambiance
  - Ratio / format
- 0h30 à 0h50 : Trois usages de l’image générative
  - Création
  - Modification / retouche
  - Image de référence
- 0h50 à 1h10 : Démonstration
  - Comparer prompt vague et prompt précis
  - Montrer l’effet du cadrage, de la lumière et de la composition
- 1h10 à 1h20 : Pause
- 1h20 à 2h20 : Génération
  - Produire des images correspondant à un emplacement précis
  - Hero
  - Cartes
  - Fiches produit / projet
  - Mockups / mises en situation
- 2h20 à 3h20 : Photoshop / Illustrator
  - Nettoyage des générations
  - Logo et textes fidèles
  - Perspective
  - Masques
  - Ombres
  - Couleur / lumière
  - Fonctions IA Adobe si utiles
- 3h20 à 3h50 : Intégration
  - B3 : replacer textes et images dans Figma
  - Vérifier cohérence entre toutes les images
- 3h50 à 4h00 : Préparer mardi
  - Ranger les assets
  - Nommer correctement les fichiers
  - Préparer le dossier du site
- À obtenir :
  - Figma B3 quasiment finalisé
  - Visuels principaux prêts
  - Mockups retouchés
  - Assets propres et classés
Mardi matin : de la maquette au site
- 0h00 à 0h30 : Anatomie d’un site
  - HTML = contenu / structure
  - CSS = apparence
  - JavaScript = comportement
  - Organisation des fichiers et images
- 0h30 à 0h50 : Lire ce que le modèle génère
  - Retrouver un titre
  - Une image
  - Une couleur
  - Une marge
  - Une interaction
- 0h50 à 1h10 : Bien demander une modification
  - Contexte
  - Fichier concerné
  - Modification précise
  - Éléments à ne pas toucher
- 1h10 à 1h20 : Pause
- 1h20 à 2h20 : Construire l’accueil
  - Donner au LLM :
    - structure
    - textes
    - images
    - couleurs
    - typographies
    - règles du Figma / moodboard
  - Ne générer qu’une page dans un premier temps
- 2h20 à 2h50 : Comparaison
  - Figma / moodboard ↔ navigateur
  - Corriger les principaux écarts
  - Faire quelques modifications manuelles simples
- 2h50 à 4h00 : Décliner
  - Pages suivantes
  - Header / footer cohérents
  - Navigation
  - Liens entre les pages
- À obtenir :
  - Site local de 1 à 3 pages
  - Toutes les pages navigables
  - Direction graphique déjà proche de la maquette
Mardi après-midi : interaction + correction + rendu
- 0h00 à 0h30 : Interaction
  - Principe simple : un événement déclenche une action qui entraîne une modification
  - Exemples :
    - filtre
    - changement d’image
    - variante produit
    - avant / après
    - accordéon
- 0h30 à 1h20 : Réalisation
  - Ajouter l’interaction avec le LLM
  - Pour les groupes en retard : priorité au site terminé
  - Interaction = bonus dans le syllabus
- 1h20 à 1h30 : Pause
- 1h30 à 2h10 : Debugging
  - Décrire :
    - résultat attendu
    - résultat obtenu
    - fichier concerné
    - erreur éventuelle
  - Éviter les demandes du type « ça marche pas »
- 2h10 à 2h45 : Contrôle qualité
  - Liens
  - Images
  - Typographies
  - Marges
  - Cohérence graphique
  - Affichage sur différentes tailles
  - Responsive = amélioration, pas priorité absolue
- 2h45 à 3h20 : Trace du projet
  - Garder uniquement les étapes significatives :
    - prompt
    - résultat
    - problème
    - correction
  - Préparer le PDF demandé
- 3h20 à 3h45 : Mise en ligne
  - Démonstration si le temps le permet
  - Publication = bonus
- 3h45 à 4h00 : Rendu
  - Site fonctionnel
  - Fichiers HTML / CSS / JS / images
  - PDF de suivi
  - Figma du design system pour les B3
  - Lien du site s’il a été publié
